V&F Dashboard v6.3 Persistent

New:
- Uploaded/processed report data is saved automatically in IndexedDB.
- Data restores when the app/browser is opened again.
- It remains saved until Clear Saved Reports is pressed.
- Supports 1 Month, Full Month Compare, and Up to Date Compare.
- Full Report PDF remains available.

Important:
Browser/app storage can be removed if Android/Chrome app data is manually cleared or the browser is uninstalled.
